SPRIGHT autoscaler

masters course project in which we extended an experimental serverless cloud framework to add autoscaling.

SPRIGHT is a serverless computing cloud framework made by a past PhD student of one of my professors. it acts as a very efficient dataplane but doesn't add any control plane functionality in its original form. for a course project, myself and a classmate added autoscaling to it.

this was a relatively short project (we had about 7 weeks to work on it) but we accomplished a lot in that timeframe. i was learning cloud computing (kubernetes, prometheus, SPRIGHT itself) as i went, and managed to get pretty familiar with it.

see the video to the right for a demo.

langs & frameworks: Kubernetes, Prometheus, eBPF

state: good grade :) (finished)
